## Highlights

- Format-aware parsing, deduplication, redaction, and safe batching.
- Raw/Parsed comparison with Raw fallback for unknown formats.
- Local chat tabs, file preview, image attachments, timestamps, and tray.
- OpenAI, Cerebras, LM Studio, Gemini, Anthropic, and custom compatible APIs.
- Portable Windows x86_64 and Linux x86_64 packages; no installer.
