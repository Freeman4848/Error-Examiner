# Gap-closure corpus

Compact synthetic fixtures based on public diagnostic formats. Values are fictional; grammar is
kept representative. Browser, Kubernetes, MSBuild, and Docker formats were checked against:

- https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS/Errors
- https://kubernetes.io/docs/tasks/debug/debug-application/debug-running-pod/
- https://learn.microsoft.com/en-us/visualstudio/msbuild/msbuild-diagnostic-format-for-tasks
- https://github.com/docker/buildx/issues/495
- https://github.com/docker/buildx/issues/681
